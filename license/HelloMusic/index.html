Приложение HelloMusic

Коротко: HelloMusic не собирает, не хранит и не передаёт никакие персональные данные. Всё работает локально на вашем устройстве.
✓ Не требует интернета ✓ Не собирает данные ✓ Без аналитики

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») описывает, как мобильное приложение HelloMusic (далее — «Приложение») обрабатывает информацию пользователя.

Приложение разработано как локальный офлайн-плеер и предназначено для воспроизведения аудиофайлов, находящихся на устройстве пользователя.

Используя Приложение, вы соглашаетесь с условиями настоящей Политики. Если вы не согласны с ней — пожалуйста, не используйте Приложение.

2. Какие данные мы собираем

Мы не собираем никакие персональные данные.

Приложение не запрашивает и не передаёт:

  • Имя, фамилию, адрес электронной почты;
  • Номер телефона;
  • Геолокацию;
  • Список контактов;
  • Данные о ваших устройствах или аккаунтах;
  • Историю использования Приложения;
  • Любые другие личные сведения.

3. Что хранится на устройстве

Все данные Приложения хранятся только локально на вашем устройстве и недоступны разработчику или третьим лицам:

3.1. Настройки приложения

  • Тёмная/светлая тема;
  • Акцентный цвет интерфейса;
  • Размер шрифта текста песен;
  • Параметры визуализации;
  • Язык интерфейса;
  • Включение/выключение анимаций;
  • Другие пользовательские настройки.

3.2. Список ваших треков

Приложение сохраняет список путей к аудиофайлам, которые вы добавили в медиатеку, чтобы восстановить список при следующем запуске. Сами аудиофайлы не копируются и не передаются — используются по указанным вами путям.

3.3. Обложки и тексты песен

Если вы добавляете свои обложки или LRC-файлы с текстами, они сохраняются во внутренней памяти Приложения и доступны только вам.

3.4. Демо-трек

Сгенерированный демонстрационный WAV-файл хранится во внутренней памяти Приложения и может быть удалён вами в любой момент.

4. Разрешения

Приложение запрашивает следующие разрешения:

4.1. Доступ к файлам и медиатеке

Зачем: чтобы вы могли выбрать папку с музыкой или отдельные аудиофайлы, которые хотите воспроизводить.
Как используется: приложение сканирует выбранную папку и отображает найденные аудиофайлы. Файлы не покидают ваше устройство.

4.2. Микрофон (RECORD_AUDIO)

Зачем: для работы визуализации звука (столбики, танцующие в такт музыке).
Как используется: системный API Android Visualizer анализирует текущий аудиопоток для построения визуализации. Звук не записывается, не сохраняется и не передаётся. Разрешение используется исключительно для чтения аудиобуфера в реальном времени.
Можно отключить: если не разрешать доступ к микрофону, визуализация просто не будет отображаться.

4.3. Уведомления (POST_NOTIFICATIONS)

Зачем: чтобы показывать уведомление о текущем треке в шторке и на экране блокировки.
Как используется: уведомление содержит название трека, исполнителя и кнопки управления. Ничего не отправляется наружу.

5. Передача данных третьим лицам

Мы не передаём никакие данные третьим лицам, поскольку не собираем их. Приложение не содержит встроенной аналитики, трекеров, рекламных SDK и подобных компонентов.

6. Дети

Приложение не предназначено для сбора данных детей и не собирает данные ни о ком из пользователей. Приложение безопасно для использования детьми под присмотром родителей.

7. Безопасность

Все данные хранятся локально и защищены стандартными механизмами безопасности операционной системы Android (изоляция приложений, внутренняя память).

8. Ваши права

Вы в любой момент можете:

  • Удалить все данные — через Настройки приложения (кнопка «Очистить плейлист») или через настройки Android (Приложения → HelloMusic → Очистить данные).
  • Удалить приложение — вместе с ним удалятся все локальные данные.
  • Отозвать разрешения — в настройках Android (Приложения → HelloMusic → Разрешения).

9. Интернет и реклама

Приложение работает без интернета. Оно не загружает никакой контент из сети, не отправляет запросы и не содержит рекламных модулей.

10. Изменения в политике

Мы можем обновлять эту Политику. Актуальная версия всегда доступна по текущему адресу. Дата последнего обновления указана внизу страницы.
